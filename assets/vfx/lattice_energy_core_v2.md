# Stability Lattice energy core v2

`lattice_energy_core_v2.png` is the runtime-selected transparent raster. It was
generated with OpenAI's built-in image generation tool on 1 September 2026
after review found that the first spherical core read as too solid.

## Production prompt

Create one small hollow wireframe crystalline energy nucleus for a Godot sci-fi
strategy HUD. Use thin emerald and mint-white light edges, a tiny central spark,
sparse internal filaments, minimal bloom, genuine transparency, and generous
empty margins. Do not include a sphere, filled glass, rings, satellites, text,
logos, watermarks, or an environment.

The runtime deliberately renders this nucleus smaller and dimmer than the
code-drawn orbital nodes. `scripts/UI/StabilityLatticeView.cs` supplies the
inclined paths, moving anchors, bright node centres, trails, pulse, and status
colours so gameplay state remains more prominent than the decorative core.
