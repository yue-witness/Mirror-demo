# Tutor voice assets

These files are AI-generated speech for the Tutor character. The library uses
a female neural voice with small delivery variations. The final pass contains
no chorus, flanging, ambience, or phase modulation. S-17 speech is
intentionally excluded.

Regenerate the library with the standalone tool at:

```text
D:\OneDrive\Mirror\tutor-voice-generator
```

`manifest.json` is the runtime source for exact rendered text, audio paths,
measured durations, delivery profiles, and characters-per-second values.
